# Firmware 3.3 parameter descriptions

daqdesc.cgi dumps from a heater running firmware 3.3, one file per UI
language. These labels differ substantially from firmware 3.2 (renamed
heating circuit pumps, reindexed interruptions, extra DHW slots starting
at 0, new sensors such as buffer T5-T7 and the ash counter) and are the
source of the corresponding `TRANSLATE` entries.
